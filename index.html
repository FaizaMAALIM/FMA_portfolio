Projets

Plateforme e-commerce en microservices

Conception et développement d'une plateforme e-commerce complète basée sur une architecture microservices, couvrant l'ensemble du parcours client : catalogue produits, gestion des stocks, commandes, paiements et notifications.

Le projet repose sur 8 services indépendants orchestrés via Spring Cloud Eureka, exposés par une API Gateway avec authentification JWT, et accompagnés d'un frontend React responsive.

Java 21 • Spring Boot • Spring Cloud • Spring Security • JWT • React • Vite • REST API • H2

Application de gestion de RDV

Conception et développement d’une application desktop permettant la gestion structurée de rendez-vous (création, modification, suppression et consultation).

L’application repose sur une architecture claire en C++ et intègre une interface graphique intuitive réalisée avec Qt Creator, mettant l’accent sur l’ergonomie et la fiabilité.

C++ • Qt Creator • Programmation orientée objet

Projet Base de Données

Conception et réalisation d’un système de gestion des inscriptions universitaires, depuis l’analyse des besoins fonctionnels jusqu’à l’implémentation de la base de données.

Le projet a inclus la rédaction d’un cahier des charges, la planification via diagramme de Gantt, la modélisation des données avec la méthode Merise, puis la création et l’exploitation de la base de données sous Microsoft Access.

Analyse des besoins • Cahier des charges • Gantt • Merise • Access • SQL

Développement Web Frontend

Réalisation rapide d’un site vitrine pour une pharmacie, mettant l’accent sur la clarté de l’information, l’accessibilité et la présentation des services proposés.

L’interface a été développée en HTML5 et CSS3, avec une attention particulière portée à la structure, au responsive design et à l’expérience utilisateur.

HTML5 • CSS3 • Responsive Design • UX/UI

Développement Web Backend

Conception et développement d’une application web complète de gestion de produits, intégrant l’authentification, la gestion des rôles et des permissions, ainsi qu’une API dédiée.

Le projet a été réalisé selon une approche API First, avec une architecture orientée objet et hexagonale. Deux versions ont été développées : une en PHP natif et une avec Laravel, en respectant les standards PSR.

PHP • Laravel • API REST • POO • PSR-1/4/7/12/18 • SQL Server • Authentification • Bootstrap

Projet Stockage

Développement d’une application web permettant le chargement de vidéos et leur traitement côté client avant envoi vers le cloud.

L’application, développée en React, extrait des frames vidéo puis les transmet vers Supabase, illustrant une logique de traitement asynchrone, de gestion des médias et d’interaction avec des services cloud.

React • Supabase • Cloud Storage • Traitement Vidéo • JavaScript

Projet Étude de Cas

Analyse complète des besoins d’un client dans le cadre d’un projet de transformation numérique, incluant un site e-commerce, un module de communication avec Sage, ainsi que des aspects de référencement et d’hébergement.

Le projet a également intégré la proposition d’une solution e-commerce adaptée et la préparation d’un plan de formation destiné aux utilisateurs finaux.

Analyse métier • E-commerce • Intégration Sage • Hébergement • Formation utilisateurs
